Управляемый список задач по приложению. Каждая запись — готовая GitHub-карточка.

## Соглашения

- **ID задачи:** `<P0|P1|P2>-<SHORT-SLUG>` (например, `P0-INPUT`).
- **Ветка:** `<type>/<id>-<slug>`, всё нижним регистром (например, `fix/p0-input-broken`, `feat/p1-app-window`).
- **Коммит ссылается на карточку:** в теле сообщения `Refs: P0-INPUT` или `Closes #<n>` после того, как создан issue.
- **Привязка Claude-сессии к задаче:** один разговор = одна задача = одна ветка. Транскрипты Claude хранятся в `~/.claude/projects/-Users-deniszagitov-Repositories-mlx-whisper-dictation/` — при закрытии задачи копируем релевантный кусок в описание PR.
- **Создать GitHub issue из карточки** (требует `gh auth login`):
  ```bash
  ID=P0-INPUT
  awk -v id="### ${ID}" '$0==id{f=1;next} /^### /{f=0} f' BACKLOG.md \
    | gh issue create --title "${ID}: $(awk -v id=\"### ${ID}\" 'index($0,id){print substr($0,length(id)+4); exit}' BACKLOG.md)" --body-file -
  ```
- **Перенести все P0 в issues разом:** `for id in P0-INPUT P0-HOTKEY; do … ; done` (см. рецепт выше).
