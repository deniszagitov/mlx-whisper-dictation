# Dictator

Этот сайт собирается автоматически из docstring и текущей слоистой структуры Python-кода в репозитории.

Приложение офлайн-диктовки для macOS на базе MLX Whisper.

Точка входа приложения: парсинг аргументов командной строки,
запуск menu bar приложения и глобальных обработчиков клавиш.

## Функциональная документация

Для описания входных и выходных данных используется правильный термин **диаграмма потоков данных**: DFD, Data Flow Diagram.

- [Функциональное описание](functional-overview.md) — сценарии, хоткеи, входы, выходы и fallback-правила.
- [Диаграммы потоков данных](data-flow.md) — DFD для диктовки, LLM, Reader, TTS, Zipper и загрузки моделей.
